# Revit Execution Specifications

This directory contains concrete technical contracts for dispatching RevitMCP capability work into a valid Autodesk Revit API execution context.

These specifications refine accepted architecture decisions and capability requirements. They are not a replacement for ADRs.

## Specifications

- `EXEC-0001-revit-execution-queue.md` — minimum serialized execution queue and `ExternalEvent` behavior required by the first Revit capability.
